## Hardware Pinout

### nRF24L01 Radio 1 - HSPI

| nRF24L01 | ESP32 GPIO |
|----------|------------|
| SCK      | GPIO 14    |
| MISO     | GPIO 26    |
| MOSI     | GPIO 13    |
| CSN      | GPIO 15    |
| CE       | GPIO 16    |

### nRF24L01 Radio 2 - VSPI

| nRF24L01 | ESP32 GPIO |
|----------|------------|
| SCK      | GPIO 18    |
| MISO     | GPIO 19    |
| MOSI     | GPIO 23    |
| CSN      | GPIO 21    |
| CE       | GPIO 22    |
